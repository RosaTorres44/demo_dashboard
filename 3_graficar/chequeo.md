# Chequeo antes de presentar

Son las cinco preguntas  ("¿Qué hace a una lámina de alto impacto?"), aplicadas al café.

| | Pregunta | En esta demo |
|---|---|---|
| 1. El título es la conclusión | ¿Si solo leen el título, ya saben qué hacer? | "Cuál es la conclusion? Qué mensaje quieres que se lleve la dueña?" |
| 2. Una idea, un gráfico | ¿Qué sobra? | Solo agrega graficos que apoyen la conclusion del titulo. |
| 3. Cada número con su definición | ¿Qué cuenta como venta aquí? | Confirmar Como se calculó |
| 4. Una acción concreta | ¿Qué le pido a la dueña? | "¿Dejamos el cupón y probamos otra cosa en noviembre?" |
| 5. Contexto y fuente mínimos | ¿Alguien puede discutir el número? | Octubre 2026, 200 clientes, 100 con cupón al azar. Fuente: `workspace.demo_dashboard`. |

## Pasarlo a la lámina
Una lámina: el título accionable, el gráfico de barras como prueba y la pregunta de sí o no al pie.

**Una lámina, una decisión.**
