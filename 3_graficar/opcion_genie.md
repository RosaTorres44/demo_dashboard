# Opción A: Genie

Requisito: Genie Agent creado (`1_setup/04_genie.md`), con la pestaña Instructions vacía.

1. **Sin instrucciones**: en el chat de Genie haz la pregunta directa (`pregunta_directa.md`) y comenta qué observar.
2. En **Configure → Instructions**, pega completo `prompt.md` (desde **Rol** hasta **Control**) y guarda.
3. Vuelve al chat y repite "¿Funcionó el cupón?". Ahora responde con el margen y el criterio.
4. Pídele el dashboard: "Arma el dashboard del pedido". Revisa que los números coincidan con `2_interpretar/problema.md`.
5. Pasa al chequeo: `chequeo.md`.
